# Quiz

1. Does a successful fixture prove live model quality?

<details><summary>Answer</summary>

No. It checks the application/SDK contract.
</details>

2. Who owns authority to execute a risky action?

<details><summary>Answer</summary>

Trusted application code and an authenticated reviewer.
</details>

3. Does cancellation undo completed side effects?

<details><summary>Answer</summary>

No. Use idempotency and reconciliation for mutations.
</details>

4. Why pin versions?

<details><summary>Answer</summary>

A stable test must target a known API and behavior.
</details>

5. What should happen after a deadline?

<details><summary>Answer</summary>

Stop work, close resources and report the failure.
</details>

6. Can untrusted source or speech approve its own execution?

<details><summary>Answer</summary>

No. Review and authorization are separate host decisions.
</details>
