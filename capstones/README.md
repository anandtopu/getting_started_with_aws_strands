# Capstones

Choose a project after its prerequisite tier. Each has a runnable baseline, reference solution, tests, evaluation cases, costs, teardown and a rubric.

- [CloudOps Copilot](01_cloudops_copilot/README.md) — Tier 3: Read measured logs and spend; cite public runbooks before proposing operational changes.
- [Trip Planner Crew](02_trip_planner_crew/README.md) — Tier 4: Coordinate flight, hotel, weather and budget specialists without giving them purchase authority.
- [Document Intelligence Pipeline](03_document_intelligence/README.md) — Tier 4: Extract receipt and invoice images, flag discrepancies, and store reviewable evidence exactly once.
- [Nimbus Support Copilot](04_nimbus_support_copilot/README.md) — Tier 5: Compose policy retrieval, booking alternatives, memory, approvals, evaluation and managed hosting.
- [Partner Network](05_partner_network/README.md) — Module 18: Request and validate a partner quote across an authenticated A2A process boundary.
